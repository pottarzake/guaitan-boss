# 暗影地牢 · BOSS 战

《怪谈博物馆》最终 BOSS 战的原生 HTML / CSS / JavaScript 离线版。

- 直接打开 `index.html` 即可游玩，不需要服务器、安装或联网。
- 线上试玩：<https://pottarzake.github.io/boss-battle/>
- 操作：WASD 移动，鼠标瞄准 / 左键攻击，空格切换能量枪与手刀，Q 开启大招（点击地面释放流星）。
- 路线：肃清前三个战斗房后，向右前往「核心王座」挑战 BOSS，或向上进入「撤离试炼」。
- 手机 / 平板请横屏，支持双摇杆触屏操作。

原文件位于 `网站开发/项目/xgnb/demos/pixel-dungeon-html/`，本仓库为独立部署副本。
